# Tres formas de comprimir el cajón de pedido

Maquetas navegables, montadas con el CSS real del sitio. Ábrelas con el
servidor local en `docs/opciones/`. No están conectadas al checkout: son
para decidir, no para vender.

| Archivo | Idea | Alto de la parte fija |
|---|---|---|
| `a-plegado.html` | Envío y pack plegados en dos botones | ~330 px |
| `b-pasos.html` | Dos pasos: qué pides / a dónde va | ~420 px por paso |
| `c-barra.html` | Ciudades en fichas y barra fija con el total | ~150 px |

Las capturas están al lado, en `opcion-*.png`.
